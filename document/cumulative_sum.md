# cumulative_sum

[Source](../src/grid/cumulative_sum.hpp)

## 概要

任意の $d$ 次元配列（`vector` などのネストしたコンテナ）に対して、**その場（in-place）で $d$ 次元累積和**を計算する関数。処理後、各要素は「その添字以下（各次元で添字 $\leq i$）の全要素の総和」になる。

二項演算 `op` を引数で差し替えられるため、通常の加算だけでなく任意のモノイド演算（例: `max`）による累積にも使える。次元数はコンテナのネスト深さから自動判定されるので、1 次元・2 次元・3 次元…を同じ関数で扱える。

`op` に渡す二項演算 $\cdot$ は、結果が矩形形状に依存せず一意に定まるよう次を満たすことが望ましい。

- 結合律：$(a \cdot b) \cdot c = a \cdot (b \cdot c)$
- 可換律：$a \cdot b = b \cdot a$

（加算・`max`・`min`・`gcd` などはこれを満たす。）

**注意点**

- 入力は各次元で長さの揃った**矩形**であること。非矩形（ジャグ配列）を渡すと `assert` で検出される（`NDEBUG` 時は範囲外アクセスとなり得る）。
- 次元判定は「`value_type` を持つか」で行うため、`string` のような `value_type` を持つ型も 1 次元コンテナとみなされる。累積和の対象要素型としては想定していない。
- オーバーフローを避けるため、要素型は総和が収まる型（`long long` 等）を選ぶこと。

## テンプレートパラメータ

| パラメータ | デフォルト | 説明 |
|---|---|---|
| `V` | — | 累積和をとる配列の型（スカラー、または `vector` 等のネストしたコンテナ） |
| `F` | `plus<>` | 二項演算 $\cdot$。`V` の最内スカラー型を `T` として `T(T, T)` の形で呼び出せること |

## 関数

### cumulative_sum

```cpp
V& cumulative_sum(V& v, F op = plus<>{})
```

配列 `v` を $d$ 次元累積和にその場で書き換え、`v` への参照を返す。`op` を省略すると加算になる。

**制約**

- `v` は各次元で矩形（同じ長さ）であること
- `op` は結合的・可換であることが望ましい

**計算量**

- $O(d \cdot N)$（$N$ は全要素数、$d$ は次元数）

**使用例**

```cpp
// 2 次元累積和（加算）
vector<vector<long long>> a = {{1, 2, 3}, {4, 5, 6}};
cumulative_sum(a);
// a = {{1, 3, 6}, {5, 12, 21}}

// 1 次元 max 累積
vector<int> b = {3, 1, 4, 1, 5};
cumulative_sum(b, [](int x, int y) { return max(x, y); });
// b = {3, 3, 4, 4, 5}

// 3 次元も同じ関数で
vector<vector<vector<long long>>> c(2, vector<vector<long long>>(2, vector<long long>(2, 1)));
cumulative_sum(c); // c[1][1][1] == 8
```
